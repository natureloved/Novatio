# NOVATIO: Short Pilot Implementation Plan

## Phase 1: Sandbox Integration (Weeks 1-2)
- **Objective:** Onboard 1 tier-2 automotive parts supplier ($20M rev) and 1 tier-1 OEM buyer on Canton DevNet.
- **Scope:** Deploy `Novatio.daml` smart contract package; issue and co-sign 5 test invoices ($250,000 total face value).
- **Integration:** Test mock ERP webhook translating SAP purchase orders into Canton JSON API calls.

## Phase 2: Private Credit Pilot (Weeks 3-4)
- **Objective:** Deploy $500,000 in pilot working capital with 1 institutional factorer.
- **Scope:** Execute live atomic DvP factoring advances on Canton DevNet using Cash asset contracts; verify zero line-item data leakage on the factorer's node.
- **Audit:** Connect regulatory observer node to exercise scoped non-consuming audit choices and export ISO 20022 `pacs.008` XML messages.

## Phase 3: Mainnet Scale & Operational CIP-0116 Staking (Weeks 5-8)
- **Objective:** Transition to Canton Network Mainnet under the AppsFactory Accelerator.
- **Operational Staking:** Fulfill CIP-0116 Featured App operational locking requirement (5M CC per app provider PartyId) as an enterprise operational cost for network throughput priority.
- **Expansion:** Connect Novatio factored receivables into Canton institutional overnight repo pools for secondary liquidity refinancing.
